Génération de QR-codes imprimables

Un média téléchargeable par code (bouton « ⬇ QR » sur chaque ligne ci-dessus) ou l'archive complète de la vue actuelle (bouton « ⬇ Archive QR (ZIP) » ci-dessus, un fichier par ligne). Le QR-code encode toujours le code numérique de la ligne — jamais le texte associé — le texte optionnel ci-dessous n'est qu'une étiquette lisible imprimée à côté.

Marge de sécurité (quiet zone) incluse — taille du carré complet du média.

300 = qualité impression standard. Sans effet en SVG (vectoriel).

Un contraste insuffisant avec le fond rend le QR-code illisible par un scanner.

Ajouter un texte lisible à côté du QR-code

Le texte « associé » ou « les deux » est tronqué au-delà de 60 caractères (avec « … ») — au-delà, un média imprimable deviendrait disproportionné.

Purger des codes invités

Suppression définitive et irréversible — n'affecte que la table des codes invités, jamais les captures ou les tags déjà posés.

Par plage de dates de création

Au moins une des deux dates est requise. Borne « Au » incluse (jusqu'à 23:59:59 ce jour-là).

Les N premiers selon un ordre

Ex. « Date de création (ancien → récent) » + 50 supprime les 50 codes les plus anciens.

Add-on — Détection de QR-codes

À chaque photo (capture simple ou photo strip), scanne l'image à la recherche de QR-codes et ajoute automatiquement chaque code détecté comme tag libre sur le média — sans action de l'invité. Pour la vidéo, ce tag n'est ajouté que si « Incruster la forme + le texte sur la vidéo capturée » ci-dessous est également coché (c'est cette option qui déclenche l'analyse de la vidéo ; sans elle, aucune frame n'est jamais scannée). Utilise les mêmes règles (longueur, nombre max. par média) que le tag libre de la tuile « Tags & ID média ». Si le contenu décodé correspond à un code de la liste ci-dessus, c'est le texte associé qui est utilisé — jamais le code numérique brut. Nécessite que « Activer les tags sur les captures » (tuile « Tags & ID média ») soit coché pour que ces tags soient visibles (galerie, journal, /bestof).

Proportionnel à la taille du QR-code détecté

Activé : la taille de la forme et celle du texte s'adaptent automatiquement, en direct, à la taille du QR-code repéré devant l'objectif (pour le recouvrir sans le dépasser) — les valeurs « Taille (%) », « Largeur » et « Hauteur » ci-dessus sont alors ignorées.

De -50 % à +50 %. Défaut : 0 %. Rétrécit ou agrandit la taille calculée automatiquement (forme et texte ensemble) — actif uniquement si « Proportionnel » ci-dessus est coché.

La forme s'applique aussi en mode « Image de fond » ci-dessous (découpe l'image selon le contour choisi). Cercle, ovale et étoile conviennent mieux à un texte court : les contenus longs peuvent être rognés par les bords ou les pointes. La forme « Cercle » est toujours un vrai disque (hauteur forcée à égalité avec la largeur en taille automatique) — plus le texte est long, plus le disque est grand.
